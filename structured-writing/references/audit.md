# 审模式：诊断现有稿件

> 何时读：用户给了现成稿子问「怎么样」「帮我看看」，或分享草稿未提要求。
> 返回诊断，不返回新稿。

---

## 前置：先定读者和场景

- **读者**：用户说了用他的；没说就从文档推断，在报告里标「（推断）」；推断不出来，这本身就是第一条发现。不知道读者就别评结构。
- **场景**：按 `scenarios.md` 判定。它决定衡量标准——
  - 准确总结工作：有没有「概括总结」？写的是动作还是结果？
  - 充分说服他人：观点开门见山吗？主动回应反对意见了吗？
  - 有力汇报方案：给了选项吗？只给一个方案的其实是「说服」。

## 诊断五步

1. **识别**：把事实、理由、结论分别标出来。辅助问题：哪些句子是可反驳的观点？哪个是总结论？支撑它的理由有哪几条？抛开判断，纯事实有哪些？（把事实和对事实的解读分开）
2. **判断**：画出实际结构，哪条支撑哪条、哪些并列。
3. **概括**：用一句话概括中心思想。**概括不出来，是最严重的发现。**
4. **数据自洽检查**（强制，见下）。
5. **标题抽取测试**（强制，见下）。

### 数据自洽检查

文中出现数字就逐项过：

| 检查项 | 做法 |
|---|---|
| 公式验算 | 写出了算式的，代入算一遍 |
| 重复数字 | 同一个数出现多次，是否一致（正文 8905、公式里 8902） |
| 分项与总计 | 分项之和是否等于总计 |
| 百分比加总 | 声称穷尽的是否加到 100% |
| 时间一致 | 「6/12–7/17」共 35 天，后面却按 30 天算 |
| 单位口径 | 同一指标是否混用单位或口径 |

只报「前后对不上」，不判断「数字本身真不真」。全部通过就写「已验算 N 处，全部自洽」。

### 标题抽取测试

把所有标题按顺序抄成一串，不带正文，只读这一串：
- 能拿到**完整论证**和**中心思想** → 合格
- 只能拿到「讲了哪些方面」→ 标题是类别不是结论，命中反模式 7
- 连方面都拿不到 → 严重

**把抽出来的标题串原样写进报告**，比描述十句都有说服力。

---

## 八项反模式

每命中一项，记下原文片段。

**1. 空洞的类别句**——「存在 3 个问题」「有以下几点体会」。只声明数量，没有信息。
改：换成实质结论。✗「该公司存在 3 个问题」✓「问题集中在现金流：应收账期从 45 天拉长到 90 天，库存周转降 40%，新增授信被暂停」。紧跟在带信息小标题前的过渡句危害小，不必列为主要问题。

**2. 结论被埋或缺失**——结论在第三段、结语里，或根本没有；开头是「随着……的发展」或只有目录预告。读者只读前三行，目录预告不是结论。
改：结论提到第一句；结语里有结论就整段挪到开头。原文没有中心思想时，试着**只用原文信息**替他归纳一句并注明出处；归纳不出来说明材料本身不支持结论。

**3. 分组不 MECE**——重叠（线上渠道 / 电商平台）、遗漏（漏了华北）、维度不统一（四个流程阶段 + 一个贯穿全流程的关注点并列）。强信号：作者自己打补丁（「这部分前面提过，这里换个角度再看」）。
改：换分类维度、用 2×2 矩阵，或把横切项单独拿出来标明。

**4. 序言塞了读者不知道的信息**——S 里出现项目代号、黑话、新概念、未公布数据，读者会停下来想「这是什么」。
改：S 只留读者已知的事，新信息挪到正文。黑话算不算问题看读者：同组周报不算，跨部门流转要解释。

**5. 同一组混用排序逻辑**——前两条按时间，第三条按区域；或同一文档几份清单各排各的。
改：同组只用一种顺序；真是两个维度就拆成两组。给上级看优先用重要性。

**6. 层级超载**——一层并列 8 条以上，或演绎链 6–7 步。
改：上提一层归并成 3 组；演绎超 4 步改归纳。

**7. 无信息标题**——「背景」「现状」「问题分析」「下一步计划」「本周进展」。
改：写成带判断的句子。✗问题分析 ✓「退货集中在两家供应商，占 68%」；✗下一步计划 ✓「建议 10 月起对这两家全检并暂停新单」。常见退化：前半部分是「名称：结论」，后半部分只剩「名称」。

**8. 平行结构不对称**——项目一有「数据 / 进展 / 计划」，项目二只有「进展 / 计划」；前三章有小结，第四章没有。缺的那格通常是「忘了写」。
改：定一套小节结构所有平行部分共用；确实没有就写「本周无」，不省略。

## 输出格式（唯一版本，九段，顺序固定）

```
【场景判断】属于「XXXX」，方向：自上而下 / 自下而上；读者：……（未说明时标「（推断）」）
【总体判断】可直接发 / 局部调整 / 需动主干 + 一句话说明改动量
【做得好的】1-3 条：引用原文 + 为什么对。没有就写「无特别之处」
【数据自洽】已验算 N 处：全部自洽 / 逐条列出对不上的位置
【中心思想】原文的中心思想是……（或：原文没有；从你的材料能归纳出……，完全来自你写的内容）
【序言检查】S 有无、是否都是读者已知 / C 有无 / Q 能否从 S+C 引出 / A 是否与中心思想一致
【标题抽取测试】抽出的标题串：…… 判定：通过 / 只能拿到方面 / 基本无信息
【问题清单】最多 5 条，每条：原文「……」→ 命中反模式 X → 建议
【修改优先级】按改了收益最大排序，不按出现顺序
```

## 判定口径

总体判断按**改动成本**，不按问题听起来多严重：

| 判定 | 口径 |
|---|---|
| 可直接发 | 无结构问题，至多措辞可优化 |
| 局部调整 | 不动主干：补标题、补一句结论、调顺序、补齐缺格，15 分钟内改完 |
| 需动主干 | 中心思想缺失、要重新分组或重排章节，得先重搭骨架 |

「结论写在结语里」如果只需整段挪到开头，判局部调整。总体判断必须和问题清单一致：有三条动主干的问题就不能判可直接发。

只评结构和数据自洽，不评文风；明显看不懂的错别字可一句带过。
