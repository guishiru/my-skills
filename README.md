# my-skills

个人整理的 Claude Skills 合集。

## Skills 列表

| Skill | 用途 |
| --- | --- |
| [prd-drafting](./prd-drafting/SKILL.md) | 把业务方模糊的、口头的需求表述，转成研发能直接接的 PRD：先把「方案」还原成「需求」，动笔前一次性确认待定项，按固定模板输出，并配流程图、异常与边界、验收标准。 |

## 使用方式

每个文件夹是一个独立的 skill，结构为 `skill名/SKILL.md`。把文件夹打包成 zip，就可以在 Claude 的 Skills 设置里上传使用。
