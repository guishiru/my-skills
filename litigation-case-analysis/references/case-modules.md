# 案由模块（M-合同 / M-婚家 / M-通用）

## M-合同

**覆盖范围补充**：股权转让、资产转让、合作开发等商事合同也归入 M-合同。

**常见请求权基础**：继续履行、支付价款、违约损害赔偿、违约金、解除合同、返还财产、缔约过失。

**S3 要件拆解要点**

- 合同成立与效力：主体资格、意思表示一致、无效事由；需要审批的合同是否完成审批。
- 合同内容：先确定条款含义，再判断是否违约。
- 违约：义务内容、不履行或不适当履行的事实、违约方。
- 损失：损失事实、数额、因果关系、可预见性；守约方是否采取了减损措施；双方是否都有过错。

**合同解释（重点）**：按顺序检查以下解释方法，每种都写出结论和理由：

1. 文义解释：条款使用的词句。
2. 体系解释：结合合同其他条款，看一种解释是否会让其他条款失去意义，或让合同失去确定性。
3. 目的解释：合同目的。
4. 交易习惯与行业惯例：该行业中这类表述通常是什么意思；需要找行业规范性文件或行业惯例的证据支撑。
5. 诚信原则。

依据：民法典关于意思表示解释、合同条款争议解释的规定（条号待核验）。

**合同变更与终止**：

- 变更原则上需要协商一致；一方主张有单方变更权的，必须有明确的合同依据或法律依据，由主张方举证。
- 合同约定以第三方（如行政审批）为准的，区分两种理解：是行政许可的前置条件，还是对一方的单方变更授权。
- 解除：区分约定解除、法定解除、协商解除，审查解除通知是否到达、是否在合理期限内行使。
- **合同可能已被后续文件或行为变更**：把签约后的函件、说明、承诺、会议纪要、付款确认按时间排开，逐份判断是否改变了原约定的条件、价款、期限。原审只看原合同文本时，这是常见突破口。
- **附条件条款**：条件是否已成就；对方是否以不正当方式阻止条件成就（可主张视为成就，条号待核验）。

**第三方作出付款或承担承诺时**，逐项区分以下几种性质，各自的责任范围不同：债务加入（与债务人承担连带责任）、保证（有从属性，需审查保证方式与期间）、履行承担（只对债务人负担义务，债权人不能直接请求）、单纯的意向表态。要依据承诺的对象（向谁作出）、措辞、是否限额、是否附条件来判断，并考虑承诺是否向政府等第三方作出却意在约束债权人。

**举证特点**：

- 主张合同已变更的一方，对变更事实承担举证责任。
- 主张对方违约的一方，一般对违约事实举证；主张已履行的一方，对履行事实举证。
- 主张损失的一方，对损失数额和因果关系举证。第三方出具的损失单据，要重点做 S2 自洽检查。

**典型证据**：合同文本及附件、补充协议、往来函件与聊天记录、付款凭证、发票、交付或验收记录、行政审批文件、行业规范性文件。

## M-婚家

**常见请求**：离婚、夫妻共同财产分割、夫妻共同债务认定、子女抚养权与抚养费、探望权、离婚损害赔偿、离婚后财产纠纷。

**S3 要件拆解要点**

- 离婚：感情是否确已破裂。法定可认定破裂的情形，以及判决不准离婚后又分居满一定期限的情形，依据民法典婚姻家庭编相关条款（条号待核验）。
- 财产：先逐项判断性质（共同财产 / 个人财产），再谈分割。取得时间、出资来源、登记情况分别列明。
- 共同债务：是否双方共同签字或事后追认；是否为家庭日常生活需要；超出日常生活需要的，债权人是否能证明用于共同生活、共同生产经营或基于共同意思表示。
- 抚养：子女年龄、子女本人意愿（达到一定年龄的应当尊重，年龄门槛与适用版本待核验）、双方抚养条件、此前实际由谁照顾。
- **变更抚养关系**（离婚后）：要件是出现了法定的变更情形（如直接抚养方不尽抚养义务、有不利于子女身心健康的行为、抚养能力明显下降等，以现行司法解释为准、待核验）。主张变更方承担举证责任。另外要考虑原抚养安排确定的时间、子女生活环境的稳定性、双方条件对比。
- **子女意见的审查**：子女年龄是否达到应当征询的程度；意见是否独立真实表达（是否受一方影响）；表述是否有歧义（如"妈妈""爸爸"在再婚家庭中所指）；法院征询的方式是否适当。

**举证特点**：

- 主张某项财产是个人财产的一方，对该财产的个人属性承担举证责任。
- 超出家庭日常生活需要的债务，由债权人对用于夫妻共同生活等事实举证（依据民法典关于夫妻共同债务的规定，条号待核验）。
- 父母出资购房、婚前财产婚后增值、隐藏转移财产等问题，涉及婚姻家庭编司法解释的具体规则，**列为待核验争点，交律师按现行司法解释判断**，不要凭记忆写出具体规则。

**S2 自洽检查重点**：银行流水与当事人陈述的收入是否一致；大额转账的时间与婚姻关系各节点（结婚、分居、起诉）的先后关系；借条日期与实际出借能力是否匹配，警惕虚构债务。

**特别提示**：婚家案件涉及大量个人隐私，输出中能用代号的地方用代号，未成年子女的信息尽量少写。

## M-通用

按 SKILL.md 通用流程执行，并在报告开头写明 SKILL.md 分流部分规定的提示语。遇到看起来像特殊举证规则的情形（如举证责任倒置、过错推定），只列为“疑似特殊规则，待律师确认”。
