# 鉴定意见拆解（S2.5）

案卷里有鉴定、评估、审计意见时必做。

鉴定意见不能作为一条整体事实收进事实表，按四段拆开，写进 elements.json 的 appraisals：

1. **检材所见**：鉴定人亲自检验看到了什么。
2. **送检前提**：鉴定所依据的、由委托方提供或告知的材料和案情。逐条标来源类型（检材所见 / 送检材料 / 委托方陈述），并挂到事实表。送检前提在卷内没有证据或有矛盾，结论随之动摇。
3. **推理**：从所见和前提推到结论的专业理由。检查两点：所用征象是不是结论的特异指标（"不能因为有四条腿就认定是马"）；结论成立时必然会有、卷内却没有的痕迹（应有而未见）。
4. **结论**：标出依据的把握程度与结论的把握程度（确定 / 倾向 / 可能 / 无法判断），结论不得强于依据。

另做四项：

- **术语对照**：结论中的关键术语，与所引标准的定义原文并排列出，逐字核对。
- **原因分级**：涉及因果时，区分根本原因、主要原因、辅助原因、诱因，检查是否把诱因当作主因。
- **质证清单**：鉴定人资质是否在有效期内；是否接触原始检材；比对样本来源是否经质证；取样与比对条件是否相同；鉴定时间是否明显滞后；是否单方委托。
- **多份鉴定冲突**：同一待证事项有多份结论不同的鉴定，检查原审采信了哪一份、是否说明理由。
- **用鉴定人自己的标准检验他**：检索鉴定人或其所属方法流派公开发表的标准、论文、访谈、在其他案件中的意见（含未被法院采信的记录），写进 appraisals 的 expert_own_standards。检查本案结论是否违背他自己说过的准确率、适用条件、所需特征数量；同一方法得出相反结论时，按他自己的标准应采哪一个。这类材料需要律师在卷外检索，检索结果和出处要能核验。

申请重新鉴定前，先评估：检材是否还在、对方能否补正、费用与周期。
