# 程序阶段叠加规则（P1 一审 / P2 二审 / P3 再审）

在 SKILL.md 通用流程的基础上，按阶段增加以下重点。

## P1 一审

- P1-原：比较可选的请求权基础（如违约与侵权竞合时选哪一个），对每个选项列出要件证据是否齐备；检查诉讼请求是否明确、可执行，计算方式是否有依据。
- P1-被：先找对方要件的缺口，再找抗辩；评估是否需要反诉、是否需要申请追加当事人；检查管辖、时效、主体资格等程序性抗辩。

## P2 二审

- 二审围绕上诉请求的范围审理。我方是上诉人时，检查上诉请求是否覆盖了所有要纠正的点；我方是被上诉人时，检查对方上诉请求范围之外的内容，提示不必展开。
- 区分两类错误：**事实认定错误**（S4 的结果）和**法律适用错误**（合同解释、法条选择、责任分配），分别列出。
- 评估二审可能的处理结果：维持、改判、发回重审，以及对应的依据（民诉法关于二审裁判方式的规定，条号待核验）。
- 检查二审新证据：是否属于新的证据，逾期提交的理由能否成立。
- 同时准备两套请求：直接改判，以及事实不清时请求发回重审。

## P3 再审

- **先过门槛**：把 S4 发现的每一个硬伤，对应到民诉法规定的法定再审事由（条号待核验），例如：有新证据足以推翻原判决；原判决认定的基本事实缺乏证据证明；认定事实的主要证据是伪造的；适用法律确有错误；等等。对应不上法定事由的硬伤，单独列为“不构成再审事由，但可以在再审审理中一并主张”。
- 区分“基本事实”和“一般事实”：只有影响裁判结果的基本事实认定错误才构成再审事由。
- 检查再审申请期限是否已过、是否已经过检察监督程序，提示律师核实。
- 主张新证据的，评估是否属于新的证据，以及是否足以推翻原判决。
