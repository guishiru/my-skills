# 外部锚点与新证据来源（S2.6）

案卷内的矛盾找完后，再往卷外找能直接检验关键事实的客观记录。卷内证据"互相印证"时，往往要靠卷外锚点才能翻转。

- **每个关键事实配一个外部锚点**：列出它可以用什么卷外记录核验（工商登记的成立或开业日期、银行流水与取款凭证、出行记录、监控录像、电子文件元数据、物品型号规格），以及调取途径（律师自行调查 / 申请法院调取）。
- **关联裁判清单**：同一当事人、同一事实在其他民事或刑事案件中的认定（案号、定性、事实认定），检查与本案是否冲突，同时执行是否会导致重复受偿。
- **证据灭失预警**：监控录像、通话记录、聊天记录、实物检材的保存期限，临近到期的提示申请证据保全。
- **电子原件与元数据**：对关键书面材料，评估是否申请调取电子原件，以生成时间、修改记录检验其所载日期。
- **同人跨案**：关键证人、鉴定人、出借人是否在其他案件中反复出现（职业证人、职业放贷人），提示律师检索。

输出"外部锚点清单"：关键事实、可核验记录、调取途径、紧迫程度。
