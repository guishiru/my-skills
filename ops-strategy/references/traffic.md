# 流量策略

### 获客渠道

核心策略（8 条）：
1. 选渠道看三者的交集：用户需求、公司目标、渠道本身擅长什么。
2. 抢先进入新兴分发平台，利用大公司反应慢的窗口期。
3. 像做产品一样做内容：先确定受众和他们最核心的焦虑，再明确内容是用来承接搜索，还是用来社交传播。
4. 按收入模式决定先招谁：靠产品自助转化的先招增长负责人，靠销售成交的先招销售负责人。
5. 付费投放分两个阶段：先小预算测试，验证这个渠道的获客成本能在可接受的周期内回本，再放量。放量门槛用自己的回本数据定，不套用别家的转化率阈值。
6. 产品还没被验证（留存不稳）时，不要指望用投放来补；产品验证后，付费投放可以作为一个常规渠道。
7. 合作推广优先考虑在目标人群中受信任的垂类小博主，用小规模测试比较它和名人、脚本化广告的单客成本，再决定投入。
8. 增长停滞时，先查现有渠道是否饱和、是否需要新渠道，不要指望小的产品修补。

### 付费投放

核心策略（8 条）：
1. 投之前先算能不能负担：用毛利口径的获客成本回收期判断（规划起点 3–12 个月，按自己的现金流定）；LTV:CAC 作为辅助参考，计算 LTV 时用保守、可验证的留存假设。
2. 主流平台的自动出价越来越依赖算法找人：默认用较宽的定向，加多套素材；效果变差时，先排查素材和转化跟踪，再考虑收紧定向。
3. 预算分为“已验证”和“测试”两部分（常见起点 70/30）；放量要渐进，每次调整后等平台学习期稳定再做下一次（常见做法是每次加约 20%、间隔数天，属于经验值）。
4. CPA 突然变差时，先看样本量、转化滞后和学习期，不要按固定倍数直接关停；改动线上账户前先出草案，并写好回滚方案。
5. 品牌词和非品牌词分开看：整体健康度看混合 ROAS，定目标、出价、分预算只看非品牌 ROAS。
6. 放量看净现金流：先算出盈亏平衡的 CPA 上限，持续加预算直到逼近这条线，而不是死守高 ROAS。
7. 再营销要分人群设计：对看过但没买的人，测试不同的产品或优惠，和重复推原来那个做对比。
8. 广告里测出的胜出信息，搬到落地页上再做 A/B 验证；漏斗中保持持续测试。

### SEO 审计

核心策略（8 条）：
1. 按优先级排查：先看能否被抓取和索引，再看技术基础、页面优化、内容质量，最后是权威度和外链。
2. 基础问题解决后，最快的收益通常来自已经排在第 8–20 位的页面。
3. Core Web Vitals（Google 的网页体验指标）达标线：LCP < 2.5 秒、INP < 200 毫秒、CLS < 0.1。
4. 多语言站点：hreflang 要包含自身并双向互指、语言代码合法、设 x-default；canonical 各自指向自己，不跨语种指。
5. 做不到真正有用的薄语种页就不要建；已有的低质量页面，按“改进、合并或 noindex”逐页决定，不要跨语种 canonical。
6. 页面层面：每页一个主关键词，标题和 URL 与之对齐，满足搜索意图，避免多页抢同一个词。
7. 用 E-E-A-T（经验、专业、权威、可信）评估内容质量。
8. 证据不足不下结论：普通抓取看不到 JavaScript 注入的结构化数据，要渲染页面后再判断。

### 应用商店优化

核心策略（7 条）：
1. 先按品牌成熟度给 App 分层（头部、成熟、挑战者），再决定是否按教科书标准评判；头部 App 偏离常规时，先假设是有数据支撑的选择。
2. 从六个维度检查：标题与副标题、描述、视觉素材、评分与评论、元数据与更新、转化信号。各维度的权重按自己类目的转化数据定，不用固定权重。
3. 按各平台的索引规则安排关键词：Apple 只索引标题、副标题和 100 字节的关键词字段，三处不重复用词；Google Play 的标题、短描述、长描述都参与索引。
4. Google Play 长描述要自然覆盖目标关键词，不追求“关键词密度”，避免堆砌。
5. 前几张截图基本决定转化，优先打磨首屏截图和预览视频。
6. 硬性红线：评分低于 4.0、长期不更新要标记；Google Play 崩溃率超过 1.09%、ANR 率超过 0.47% 会被降低曝光（平台官方阈值）。截图数量参照同类目头部 App。
7. A/B 测试结果按统计显著性和置信区间判断，事先算好样本量；提升幅度只用来判断这个结果在业务上值不值得做。

### 渠道经济学

核心策略（7 条）：
1. 按产品复杂度和客单价选择渠道组合（直销、经销、分销、平台、伙伴）。
2. 比较渠道要算全成本贡献毛利：渠道收入减去渠道折扣、产品成本（按实际交付成本算，不随折扣变化），再减去分摊的销售、市场、伙伴培训、运营、客服成本。
3. 伙伴分级按结果设门槛（营收加续约率），每升一级要在合理周期内可达；每年复核，可以降级；在设计上堵住折扣叠加套利。
4. 各级伙伴的折扣和返利水平，按自己的毛利空间和竞品政策倒推，逐级递增，不套用所谓“标准结构”。
5. 按伙伴类型配激励组合：交易型伙伴以前端折扣为主，增值型伙伴提高返利和服务激励的比重；市场基金和单笔奖励必须挂钩线索产出，并且可审计。
6. 渠道冲突默认“先报备者得单”；破例要书面说明，并补偿落败方。
7. 价格政策：最终客户在各渠道看到的价格保持一致，避免客户在渠道之间比价；伙伴的利润来自给伙伴的折扣，而不是客户价差。
