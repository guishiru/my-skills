### 顺序色（蓝）

| 用途 | 浅底（浅 → 深） | 深底（暗 → 亮） |
|---|---|---|
| 漏斗、等级（≤5 级） | `#86a9e6` `#5f8bd9` `#3a6cc8` `#2552a6` `#183b7c` | `#3d66bd` `#5583d6` `#76a0e6` `#9dbcf0` `#c6d7f6` |
| 热力矩阵 / 6–7 级 | `#dce7f8` `#b5cbf0` `#86a9e6` `#5f8bd9` `#3a6cc8` `#2552a6` `#183b7c` | `#31509a` `#3d66bd` `#5583d6` `#76a0e6` `#9dbcf0` `#c6d7f6`（+ 背景色作最低档） |

- 深底上“数值越大越亮”，与浅底方向相反。
- 7 级以上：合并阶段或分档，不要再插值（相邻档会分不清）。
- 浅端颜色和背景对比度不足时，脚本 `--ordinal` 只会警告：条旁或格内必须标数字。格内文字颜色取“深字/白字中对比度较高者”。

### 发散色（低于 ← 灰 → 高于）

浅底：`#c0392b` `#e8907e` `#d9dbde` `#7fa6e0` `#2563c9`
深底：`#e0675a` `#9a5048` `#4a4d52` `#3f6cb0` `#5b8fe0`
中点必须是灰色；两端一冷一暖。用于达成率、同比增减、偏离均值。只用两端时（增长/下滑两色），直接取两端色。

### 状态色（保留含义，必须配图标或文字）

| 状态 | 色值 |
|---|---|
| 良好 | `#2e8b57` |
| 预警 | `#e0a100` |
| 严重 | `#e06c1a` |
| 危险 | `#c62828` |

当一个系列本身就表示好坏（如错误率、是否达标）时，用状态色；只是区分对象时，用分类色。同一张图里两者不能混用。

**达标 / 未达标这类二值**：未达标用发散色红端 `#c0392b`，达标用弱化灰（只想突出问题时）或发散色蓝端（两者都要讲时），并配“未达标”标签或图例。不要用状态色的四档。

## 先定“页面颜色表”

一页（或一个看板、一份 Excel 汇报）有多张图时，**先列出颜色表再画图**：每个对象（渠道、城市）或每种含义（增长/下滑、实际/目标）对应一个颜色，全页通用。

- 同一个对象在不同图里颜色必须一致。如果某张图要用发散色表示“增/减”，而这些对象在别的图里已有分类色，就二选一：
  - 这张图改用“主色 + 灰色”（只突出要讲的对象）；或
  - 全页都不给对象分配分类色，只用含义色（增长蓝 / 下滑红 / 其余灰）。
- 结论有两个主角（如“小程序超过 App”）：两个主角各用一个分类色，其余灰色。三个以上主角 → 考虑拆图。

## 校验脚本怎么用

- 把一张图里用到的**所有颜色**一起传入。灰色会被自动识别为弱化色，只检查对比度。
- 顺序色、热力色加 `--ordinal`；散点、地图、小多图加 `--all-pairs`；深色模式加 `--bg "#18191c"`。
- 发散色不是单调的，不用脚本校验，按本页给定色值使用即可。

## 四种用途，各守一条规则

1. **分类**：颜色只表示“这是谁”。按顺序取色；对象在筛选后保持原来的颜色。
2. **顺序**：类目顺序有意义时（漏斗阶段、S/M/L、年龄段）用顺序色。调换类目顺序会改变含义的，就是顺序数据。
3. **发散**：有明确基准（0、100%、均值）时用发散色，中点为灰色。
4. **状态**：只表示好坏，不能拿来当“第 4 个系列”的颜色。

## 常见错误

- 名义类目（产品、城市）按数值深浅上色：重复编码了长度信息，还浪费了颜色通道。单一系列就全部用主色。
- 用彩虹色表示大小：应该用单色由浅到深。
- 发散色中点用了彩色，或两端都是冷色：读者看不出“正负相反”。
- 浅色系列色用作文字颜色：对比度不够，文字一律用文字色。

## 深色模式

使用同一套色相。网页里分别定义浅色和深色两组 CSS 变量，深色模式下单独校验（`--bg "#18191c"`），不要靠反色自动生成。
