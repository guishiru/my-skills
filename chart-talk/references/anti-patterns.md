# 常见错误清单

出图后逐条对照。命中任意一条，修改后再交付。复核模式下，命中的条目就是问题。

## 结论与叙事

| 错误 | 为什么不行 | 改法 |
|---|---|---|
| 标题是主题（“各渠道订单量”） | 读者要自己找结论，而且可能找错 | 把结论写成标题 |
| 一张图塞进两三个结论 | 读者不知道该看哪里 | 拆成多张图，每张一个结论 |
| 结论与图不符（标题说“增长”，图上看不出来） | 失去信任 | 改结论，或换一种能显示该结论的比较 |
| 相关写成因果（“全靠”“导致”“带动”） | 误导决策 | 写“同时出现”“越…越…”，并说明其他可能的原因和样本量 |
| 小基数百分比（3→6 单写成“+100%”） | 夸大 | 同时给出绝对值或基数 |
| 只挑有利的时间窗口 | 选择性呈现 | 给出完整周期，或说明为什么只看这一段 |

## 误导性画法

| 错误 | 为什么不行 | 改法 |
|---|---|---|
| **双坐标轴** | 两个刻度的对齐方式是任意的，会凭空“制造”相关或交叉 | 拆成两张图，或换算成指数（基期 = 100）共用一个坐标轴 |
| 柱/条的数值轴不从 0 开始 | 长度不再与数值成比例，差异被放大 | 从 0 开始；只看差异就改画变化量 |
| 3D 图表 | 透视会让前面的柱子显得更大 | 用 2D |
| 梯形漏斗图、气泡按半径编码 | 面积随数值的平方变化，差异被夸大 | 用横向条形；气泡按面积编码 |
| 时间轴不等距或缺月份不标注 | 趋势斜率失真 | 等距排列，缺失处留空并标注 |
| 累计值与当期值混在一张图 | 累计曲线永远在上升，会掩盖当期下滑 | 分开画，或只画当期 |
| 均值掩盖分布 | 少数极端值会拉偏均值 | 同时给中位数，或画分布 |
| 多个饼图并排比较构成 | 角度很难跨图比较 | 用多根 100% 堆叠条 |
| 占比标签合计不是 100%（常见于截断取整） | 读者会怀疑整张图 | 四舍五入，并让最大项吸收误差；或注明“因四舍五入合计不为 100%” |
| 量 + 率用双轴叠在一起 | 两个刻度随意对齐，制造假关系 | 成对条形或散点图 |

## 选图

| 错误 | 改法 |
|---|---|
| 饼图超过 5 块，或比较相近的数值 | 用横向条形图（排序） |
| 竖柱配长类目名，文字倾斜 45° | 改用横向条形 |
| 项目比较没有排序 | 按数值排序（类目有自然顺序时除外） |
| 只有一个数字也画图 | 改用指标卡 |
| 讲“某一个”的故事却用了 8 种颜色 | 突出那一个，其余灰色 |
| 雷达图做精确比较 | 用表格或小多图 |
| 折线连接无序的类目（如城市） | 类目之间没有连续性，改用条形图 |

## 颜色

| 错误 | 改法 |
|---|---|
| 凭肉眼判断色弱能否分辨 | 运行 `scripts/check_palette.py` |
| 名义类目按数值深浅上色 | 单系列统一用主色 |
| 彩虹色表示大小 | 单色由浅到深 |
| 发散色中点用彩色 | 中点改为灰色 |
| 筛选后颜色重新分配 | 颜色绑定对象，不绑定排名 |
| 超过 8 种分类色 | 合并为“其他”，或拆成小多图 |
| 状态色（红绿）当普通系列色用 | 分开使用 |
| 红绿是唯一的区分方式 | 加图标、文字或形状 |

## 视觉细节

| 错误 | 改法 |
|---|---|
| 每个点都标数字 | 只标端点、最值、主角 |
| 粗重的网格线或虚线网格 | 1px 浅灰实线 |
| 标签被裁切或互相重叠 | 移到外侧，或去掉，交给悬停提示或表格 |
| 单系列也放图例 | 去掉，标题已经说明 |
| 没有单位或口径 | 补充副标题 |
| 图例顺序和图中顺序相反 | 保持一致 |
| 文字用浅色系列色 | 用文字色 |
| 网页图表容器高度不含坐标轴，出现内部滚动条 | 容器高度包含坐标轴区域，或开启 containLabel |
