# 复核模式

用于审别人的图表、汇报页或看板。目标不是挑毛病，而是回答：**这张图能不能作为决策依据？要改什么？**

## 先判断：只审图，还是审整份汇报？

| 材料 | 做法 |
|---|---|
| 一张图 / 一页图表 / 看板 | 按下面第 0–4 层完整检查 |
| **整份汇报（有文字论证 + 图表）** | **联合复核**：论证交给 critical-reading，本 skill 只管图（见文末“联合复核”）。没有装 critical-reading 时，照常完整检查 |

分工原则：**critical-reading 管“说得对不对”，本 skill 管“图有没有如实呈现数据”。** 同一个问题只报一次。

## 第 0 步：还原意图

先用一句话写出“这张图想说的结论”。
- 如果能从标题直接读出来 → 记下，后面核对它是否成立。
- 如果要猜 → 这就是第一个问题（结论层·严重）。
- 只看图片无法确认数据时，明确说“基于图面读数”，不要假装看过原始数据。读数方法：数据标签优先；没有标签就按坐标轴刻度估读，并写明精度（如 ±0.1）。
- **意图有多种读法时**：能问就先问用户；不能问（或用户要求直接改）就选信息量最大、最能被数据支撑的读法，并在报告里列出其他读法的备选标题。

## 第 1 层：结论（最重要）

联合复核时，本层只查标 ★ 的三项（图文一致、数字验算、口径），其余属于论证问题，交给 critical-reading，不重复报。


- [ ] ★ 标题是结论还是主题？**图和正文说的是同一个数吗**（正文写 +35%，图上算出来 +28%）？
- [ ] ★ 图上的数据能支撑标题吗？读出关键数字，自己验算（环比、占比、合计）。**占比标签合计约等于 100% 吗？** 同一个对象在不同图里的数字、口径（如一张有“其他”、一张没有）一致吗？
- [ ] ★ 图上的口径完整吗：时间范围、单位、来源、是否剔除了某些数据？
- [ ] 对比基准清楚吗（同比/环比/目标/均值）？
- [ ] 有无夸大：小基数百分比、相关当因果、只挑有利的时间窗口？
- [ ] 一张图是否只讲一个结论？

## 第 2 层：选图

- [ ] 结论属于哪种比较（成分/项目/时间/频率/相关），图形是否匹配（见 `choosing-a-form.md`）？
- [ ] 是否根本不需要图（只有一个数）或应该用表格（类目太多）？
- [ ] 项目比较是否排序？要突出的项是否被突出？

## 第 3 层：误导（逐条对照 `anti-patterns.md` 的“误导性画法”）

- [ ] 双坐标轴？
- [ ] 柱/条的数值轴不从 0 开始？
- [ ] 3D 透视、面积编码、梯形漏斗？（饼图轻微阴影算视觉问题，3D 透视才算误导）
- [ ] 量 + 率用双轴硬凑在一张图？
- [ ] 时间轴不等距、缺期？
- [ ] 累计值与当期值混用？均值掩盖分布？

## 第 4 层：视觉

- [ ] 颜色：有无彩虹色、超过 8 色、红绿作为唯一区分、状态色滥用？（能拿到色值时，运行 `scripts/check_palette.py`）
- [ ] 标签：每个点都标、重叠、裁切、缺单位？
- [ ] 图例：单系列有图例、多系列无图例、顺序不一致？
- [ ] 网格和坐标轴是否喧宾夺主？

## 严重程度

| 级别 | 含义 |
|---|---|
| **严重** | 结论不成立或会误导决策（数据算不对、占比合计不对、双轴制造假相关、截断坐标轴放大差异、相关当因果；标题是主题且图也看不出结论） |
| **重要** | 结论成立，但读者很难看出来，或容易误读（选错图、口径缺失；标题是主题但图本身能看出结论） |
| **建议** | 不影响判断，但影响专业度（配色、标签密度、网格） |

## 问题代号（与 critical-reading 的代号体系兼容）

| 代号 | 问题 |
|---|---|
| `V1` | 双坐标轴 / 量+率硬凑 |
| `V2` | 柱/条数值轴截断 |
| `V3` | 面积或体积编码失真（3D、梯形漏斗、气泡按半径） |
| `V4` | 选错图形（饼图块太多、折线连无序类目、该排序没排序、该用表格用了图） |
| `V5` | 图文不一致（正文数字与图对不上、标题与图不符） |
| `V6` | 图上数字或占比验算不通、口径不一 |
| `V7` | 时间轴失真（不等距、缺期、只截有利区间的画法） |
| `V8` | 视觉干扰（彩虹色、红绿唯一区分、标签过载、主题式标题、缺单位） |

## 输出模板（单独审图）

```
## 复核结论
一句话：能否作为决策依据 + 最大的问题。

## 这张图想说的
<还原出的结论>；<是否成立，依据是什么>

## 问题清单
| # | 级别 | 层 | 问题 | 为什么是问题 | 怎么改 |
|---|---|---|---|---|---|
| 1 | 严重 | 误导 | 双坐标轴 | … | … |

## 改进方案
- 建议标题：<结论式标题>
- 建议图形：<比较类型> → <图形>，<强调方式>
- 需要补充的口径或数据：…
```

问题按严重程度排序；同一级别内按“结论 → 选图 → 误导 → 视觉”排序。
没有问题的层直接写“未发现问题”，不要凑数。
用户要求时，按出图模式重画一版，并且和原图放在一起对比。重画时用不到的原图数据（如饼图）可以删掉，但要在报告里说明删掉的理由；原图数据有问题（合计不对、口径不一）时，不要沿用，标注“待同事补充”。

## 联合复核（整份汇报 + critical-reading）

适用：材料既有文字论证又有图表，且环境里有 critical-reading。

**步骤**

0. **先通读全部材料，看完所有图**，做一张“数字交叉核对表”：同一个数在正文、表格、图里各是多少，统计范围（哪些城市、哪段时间）是否一致。很多关键矛盾只有对照着看才能发现，所以这一步在两个 skill 分头审之前做。
1. **critical-reading 审论证**：按它的流程判体裁、主张分类与逐条判定、找承重问题。
2. **本 skill 审每张图**：查 V1–V8 和第 1 层三项 ★。
3. **按下表归属，同一事实只报一次**：

| 情况 | 归属与代号 |
|---|---|
| 图上**画的数**和正文**写的数**不同（图标 28%，正文写 35%） | 图表 `V5`，写明哪边错 |
| 用材料自己的数据**算不出**正文的结论（正文和图都写 9.4→12.0，却说 +35%） | 论证 `E7` |
| 正文或表格内部合计算不通 | 论证 `E7` |
| 统计范围/口径前后矛盾（即使证据来自图） | 论证 `E3`，注明证据来自哪张图 |
| 图上占比合计不对、图内数字算不通 | 图表 `V6` |
| 主张本身推不出（因果、外推、只算收益） | 论证（critical-reading 代号） |
| 数据没错，画法让人看错（双轴、截断、面积） | 图表 `V1–V4` |
| 结论和画法同时有问题（如因果结论 + 双轴放大“同步”） | 报一条，写两个代号（`E5 + V1`） |
| 基期/时间段太短 | 材料里**没有**更早数据 → 论证 `E4`（要求补数据）；有更早数据却没画 → `E4 + V7` |

4. **定级**：
   - **承重** = 会改变决策的问题：论证类按 critical-reading 判断；图表类须同时满足“chart-talk 定为严重”和“是主结论的证据”。
   - **一般** = 其余进问题清单的问题。
   - **图表细节** = 不影响判断的视觉问题（主题式标题、配色、标签），放末尾一行一条，不进问题清单。
   - 【承重问题】段列**全部承重问题的编号**，按影响大小排序，不列能力类别；不要为了凑数合并或降级。承重问题超过 5 条，通常说明材料主干整体不成立，在整体判定里直说。
   - 一条问题可以有多个代号：第一个是主代号（根源），其余是次代号，例如 `E5 + V1 + V2`。
   - 同一组数据牵出两个不同根源的问题（如饼图合计 103% 是画法/计算问题，背后的“新客多在非试点城市”是口径问题），可以拆成两条，互相注明编号，分别定级。
   - 问题清单排序：承重在前，一般在后；同级内按影响大小排。
5. **整体判定只看承重问题**。图表细节再多也不能拉低判定。

**合并后的输出格式**

```
【材料判读】体裁 + 标准 + 是否含图表（几张）
【数字交叉核对】关键数字在正文/表/图中的取值，不一致的标出（只列有问题的或关键的）
【核心主张】
【主张判定】表格：主张 · 类型（F/S/I/O/P/U）· 判定档位
【站得住的部分】
【承重问题】全部承重问题的编号 + 一句话，按影响排序
【问题清单】每条：编号 · 来源（论证/图表）· 代号 · 承重/一般 · 引用原文或指明哪张图 → 为什么 → 要补什么/怎么改
【图表细节】一行一条（可省略）
【整体判定】
【补强后的版本】
【改图建议】每张有问题的图：建议标题 + 比较类型 → 图形；数据待核实的写“核实后重画”
【你该追问什么】最多 3 条
```
