# 选图：比较类型 → 图形

## 第 0 问：真的需要图吗？

| 数据是… | 用 | 不要用 |
|---|---|---|
| 一个当前值（可带变化） | **指标卡**：大数字 + 较上期变化 + 迷你趋势线 | 只有一根柱子的柱形图 |
| 3–6 个核心指标 | 一排指标卡 | 分组柱形图 |
| 一个比例对一个上限（达成率） | 进度条 | 只有两块的饼图 |
| 超过 7 个类目，每个都要精确读数 | 表格（可加条形底纹） | 更多颜色 |

## 五种基本比较

### 1. 成分比较（占比、构成）
- 首选 **100% 横向条形**或单根堆叠条：块之间容易比较，类目名可横排。
- 饼图仅在：只有一个整体、≤5 块、要传达“大约一半/三分之一”时使用。最大块从 12 点钟方向开始顺时针排列，或者把要强调的那块放在 12 点钟位置。
- 比较**多个整体的构成**（如各城市的渠道构成）→ 多根 100% 堆叠条，不要用多个饼图。
- 构成**随时间变化** → 100% 堆叠柱形图（期数少）或堆叠面积图（期数多）。

### 2. 项目比较（排名、高低）
- 首选**横向条形图**：类目名可以完整显示，从上到下排序。
- **按数值排序**（除非类目本身有自然顺序，比如年龄段）。
- 要讲某一项 → 该项用主色，其余灰色。
- 有正负值（如增长率）→ 发散条形，正负用冷暖两色，0 线明显。

### 3. 时间序列（趋势）
- 强调每期的量（对比目标、比较各月大小）→ 柱形图（期数 ≤12 为宜）。
- 强调走势、交叉、拐点，或有多个系列 → 折线图（期数少也用折线）（2px，最多 4–5 条线；更多就用小多图或突出一条）。
- 时间永远放在横轴，从左到右。
- 时间间隔必须相等；有缺失月份要留空并标注。
- 同比：今年和去年两条线，去年用灰色。

### 4. 频率分布
- 直方图：柱子之间不留缝（表示连续区间），区间宽度相等。
- 两组分布对比 → 两条分布折线，或两张小多图共用纵轴。
- 均值会掩盖分布：报均值时同时给中位数，或者直接画分布。

### 5. 相关性
- 散点图，横轴放“原因候选”，纵轴放“结果”；可加趋势线并标注 R²。
- 读者不熟悉散点图 → 成对条形图：左边按 X 排序，右边对应 Y，看两边是否同向变化。
- 永远写明“相关不代表因果”的边界。

## 运营场景专用

| 场景 | 推荐图形 | 要点 |
|---|---|---|
| **实际 vs 目标** | 差距明显（≥10%）：柱形（实际）+ 目标横线；差距小（<10%）：直接画**差额**（实际−目标）发散柱，或达成率柱 + 100% 参考线 | 同一个坐标轴，不要双轴。差距小时“柱 + 目标线”看不出缺口，标签还会被目标线穿过 |
| **达成率排名** | 横向条形 + 100% 参考线 | 低于 100% 的用警示色，配数字标签 |
| **漏斗转化** | 横向条形（从上到下按阶段，左对齐），标注人数和相对上一步的转化率，最大流失一步加粗或用强调色 | 阶段是顺序数据 → 单一色相由深到浅（6–7 级用 color.md 的长色阶）；不要用梯形漏斗或居中条形（面积和位置会误导） |
| **留存 cohort** | 热力矩阵（行 = 首单月，列 = 第 N 月） | 单一色相顺序色，格内标百分比 |
| **环比/同比变化** | 发散条形（变化值），或哑铃图（前后两点） | 0 线清楚，正负方向用颜色 |
| **贡献拆解**（GMV 变化由谁贡献） | 瀑布图；变化量远小于总量时改用发散条形（只画变化量） | 起点、终点用中性色，增加和减少用两种颜色。瀑布图从 0 开始会把小变化压扁，此时画变化量更清楚 |
| **量 + 率**（订单量与转化率、GMV 与毛利率） | 成对横向条形（左量右率，共用类目顺序）；想看两者关系用散点图 | 这是双坐标轴最常见的诱因，禁止用双轴 |
| **多城市×多指标** | 表格 + 条件格式，或小多图 | 不要用雷达图做精确比较 |
| **构成变化** | 100% 堆叠柱 | 重点类目放在最靠近基线的位置，便于比较 |

## 系列数量阶梯（分类色）

| 系列数 | 处理 |
|---|---|
| 1 | 单色，不需要图例（标题已说明） |
| 2–4 | 分类色 + 图例 + 直接标签 |
| 5–8 | 图例必备；考虑突出 1 个、其余灰色 |
| >8 | 合并尾部为“其他”，或拆成小多图；不要再加颜色 |
