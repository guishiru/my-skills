# 线条、标签、图例

数据是图上唯一可以“抢眼”的东西，其余一律退后。

## 图元规格

| 图元 | 规格 |
|---|---|
| 柱 / 条 | 粗细不超过类目宽度的 60%（网页约 ≤24px）；数据端可做 2–4px 圆角，基线端保持方角 |
| 折线 | 2px，拐点圆滑连接；强调线可 2.5–3px，背景线 1.5px 灰色 |
| 数据点 | 直径 ≥8px；与线交叠处加一圈背景色描边 |
| 面积填充 | 系列色约 10–15% 透明度 |
| 网格线 / 坐标轴 | 1px 实线，浅灰；不用虚线（虚线会被误读为预测或阈值） |
| 堆叠块之间 | 留 1–2px 背景色缝隙，不要画边框 |

## 标签

- **选择性标注**：折线、散点、密集柱形只标终点、最值、主角系列、要讲的那个点。每个点都标数字等于没标。
- **例外**：类目 ≤12 的条形/柱形可以全部标数字，此时去掉数值轴。100% 堆叠图只标要讲的那一段，不要每块都标。
- 条形图标在条的末端外侧，柱形图标在柱顶，折线图标在线尾。
- 放不下就挪到外面或去掉，绝不裁切或重叠。
- 数字格式：千分位；≥1 万用“万”（12.9 万）；百分比保留 0–1 位小数；单位写在副标题或轴标题，不要每个标签都带单位。
- **文字一律用文字色**（主文字 / 次文字），不用系列色；靠旁边的色块、短线来对应系列。

## 图例

- 2 个及以上系列必须有图例；1 个系列不要图例。
- ≤4 个系列时，优先在线尾或条旁直接标注名称，图例作为补充。
- 图例顺序与图中系列的视觉顺序一致（例如堆叠从上到下）。
- 线尾标签互相挤在一起时：用引导线、拆小多图，或只保留图例，不要硬把标签错开。

## 坐标轴

- 柱/条的数值轴从 0 开始。
- 刻度取整（0 / 50 / 100），≥1000 用 1K 或“万”。
- 横轴类目名过长：改用横向条形，而不是把字倾斜 45°。
- 有直接标签覆盖所有值时，可以去掉数值轴。

## 指标卡（KPI）

- 结构：`指标名` · `数值`（大字号、加粗）· `变化`（带正负号，写明对比期：较上月 +3.2%）· 可选 12 期迷你趋势线。
- 变化的颜色 = 方向 × 好坏（成本上升是坏事，用警示色）。
- 一个页面只能有一个“英雄数字”（最大的那个）。
